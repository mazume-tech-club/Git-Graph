# 「未マージ」は HEAD ではなくマージ基準で判定する

v1.x では「HEAD に取り込み済みか」で未マージを判定していた。
並行開発では各ワークツリーが別の feature ブランチをチェックアウトしており、
HEAD 基準だと見るワークツリーによって同じブランチの判定が変わる。
そこで判定相手を「マージ基準」（ローカルの main → master → develop の順で自動検出、
リポジトリごとに設定で上書き可）に固定した。
リモートの既定ブランチ（origin/HEAD）を基準にする案は、ローカルで取り込んだが
push していないものを未マージと誤判定するので採らなかった。
